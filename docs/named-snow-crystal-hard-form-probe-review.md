# Named snow-crystal hard-form probe review

This table reviews the second 24-process GG+ tranche. The defining visual criteria follow
[Kenneth Libbrecht's Guide to Snowflakes](https://www.its.caltech.edu/~atomic/snowcrystals/class/class-old.htm),
including its description of triangular crystals as truncated triangles or three-cornered stars.
These are product morphology judgments, not physical validation. Exact report and contact-sheet
bindings are in
[`named-snow-crystal-hard-form-probe-review.json`](named-snow-crystal-hard-form-probe-review.json).

| Named family | Four-variant result | Route decision / next work |
|---|---|---|
| Scrolls on Plates | Raised lips were overwhelmed by plate and axial growth. | GG+ early-stop search with one fixed lip seed. |
| Triangular Forms | Threefold internal ridges survived, but every outer outline became hexagonal. | GG+ early-stop search for a retained truncated-triangle outline. |
| Cups | Every height elongated into a nearly full hollow column. | GG+ early-stop search with one fixed cup seed. |

| Needle Clusters | End-on lobes separated, but oblique views remained one fused parallel envelope. | Move to explicitly labeled Compose using accepted needle components in distinct orientations. |
| Hollow Plates | All four cavity radii retained a centered cavity in a plate-like form. | Advance all four as production candidates; accept none yet. |
