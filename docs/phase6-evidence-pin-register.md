## 1. What this is

This register enumerates every surface that touches a Phase 6 evidence artifact and states what
pins it — where a *pin* is anything that would make an unauthorised change detectable: a gated hash,
an explicit CLI flag, a recorded and compared field, a test, a preflight check, or a tracked
digest a human can recompute. It exists because four instances of one defect — *a value reaches the
runs through an unpinned path while every hash and test stays green* — were found one at a time, each
by a different accident (ADR 0031's `paramSet`; seven more default-backed values; `points.json`
carrying no per-row `paramSet`; `largestExtent` recorded but never checked). This is the systematic
pass that replaces finding them one at a time. Every row below was reached by reading code and
artifacts, not documents; roughly seventy of the mutations were **executed** against a working tree
or a scratch copy of the artifacts, and where execution contradicted the reading, the executed result
is what is recorded — nine surfaces originally written up as forgery paths turned out to be pinned,
and several pins turned out to be weaker or stronger than the code comments claim. The register
distinguishes three states that are routinely conflated: **unpinned** (nothing anywhere would
disagree), **pinned but unchecked** (a record exists that a human must compare by hand), and
**checked** (something automated fails). A fourth state matters here and is called out explicitly:
**test-only**, because this repository has no CI — `.github/workflows/` contains one workflow and it
deploys `docs/education` to Pages — so every vitest assertion is human-triggered.

## 2. The register

Sorted: unpinned criticals first, then unpinned highs, then pinned-but-unchecked, then mediums, lows,
and finally the surfaces that are genuinely covered. `MUT:` is the concrete undetectable mutation
required by the audit protocol. `EXECUTED` means the mutation was run and nothing caught it;
`executed-elsewhere` means another lane ran it; `not executed` means it is constructed by inspection.

Legend for **checked automatically?** — `no` (nothing), `test only` (a vitest assertion, and there is
no CI), `preflight` (fail-closed at evidence-production time), `hash` (inside a gated manifest),
`by hand` (a tracked record a human must recompute).

## 4. Pinned correctly

Recorded so this reads as an audit and not a complaint. Fourteen surfaces are genuinely covered, and
in nine cases execution **overturned** a claimed forgery path.

- **The swept axes and condition selectors** (P1) — four independent layers: gated hash, required
  explicit flag, `--param-set` checked by value in preflight, test assertions, and per-row recording
  that matches `phase6SweepGrid()` on all 204 points with zero σ disagreement.
- **`PHASE6_SIGMA_WATER_ANCHORS`** (P6) — the model the rest of the surface should copy: membership in
  the gated manifest **plus** an independent computational referee (Murphy & Koop 2005 recomputed
  in-test, every anchor within 2%). No mutation constructible.
- **The interpolation scheme and the extrapolation ban** (P7) — gated, plus 12-decimal midpoint
  assertions on every interval that pin the *scheme*, not just endpoints, plus throws at both ends.
- **The regime table and the ambiguity band** (P4, P5) — pinned on both axes: the values *and the
  array order* are inside the gated hash, and the logic is pinned by exact-partition assertions.
  Operator-flip mutations are provably no-ops on the registered grid.

  `[0.6666, 0.6667)`, and `→ 0.9` was executed and caught.
- **The four `invalid` predicates** (P2) — all four deletions executed and all four caught; the test's
  case table constructs exactly the `symmetryError: 0.02` fixture the first reading said nothing
  constructs.
- **Anchors 1–7 of all three digitized arrays** (P8) — the libm digest samples every integer
  temperature from −2 to −30 plus the three boundaries, so 21 of 27 numbers are pinned **bit-exactly**;
  four separate anchor mutations were executed and every one moved the digest.
- **`pressurePa`** (P9) — pinned indirectly and elegantly: the fingerprint evaluates `kineticLength` at
  the fixture pressure, so 101325→100000 moves the digest to `beaa47ff`.
- **`relaxTol`, `divTol`, `relaxMaxSweeps`, `seedRadius`, `rngSeed`** (P13, P14) — five claimed forgery
  paths that are in fact caught, by a third copy nobody had enumerated: the hard-coded `HEADER` string
  at `phase6-sweep.test.ts:257-263` plus its 12-case drift table, driven through the new
  `phase6ConfigFailures`. This is the best-designed new pin in the tree: it checks what the **child
  reported**, not what the parent intended, which is precisely the ADR 0031 lesson.
- **`metric-thresholds` prose** (R7's one exception) — moving it is caught **three** times: the
  combined hash moves and preflight gates it unconditionally (`phase6-sweep.ts:151-156`), and the
  append-only revision history (`phase6-protocol.test.ts:126`) forces an explicit ADR-referenced row.

- **`gate3`'s and Phase 5's plate/hollowColumn/dendrite presets** (R93, R78) — resolved numbers are
  embedded in `GATE4A_MANIFEST_SHA256`, so a preset change moves a frozen hash and fails 47 tests;

- **`gate4a`'s solver source hashes** (R77) — the only pin in the repository that content-hashes physics

- **`8aeb2b80…` at `390fe35`** (P12) — verified by recomputation; the canonicalizer is byte-identical
  between the two commits, so there is no canonicalization drift. Pinned by git immutability.
- **The canonicalization primitive itself** (R80) — `canonicalJsonSha256` and friends are pinned by
  total coupling: every frozen digest in the repo flows through them, so any change moves all of them
  at once. No value-selective mutation constructible.
- **Phase 5's integrity chain** (R89) — all 172 recorded source hashes match the git blobs at the
  recorded commit; all 75 artifact-index entries match on disk; the aggregate re-derives itself and
  compares bytes. The evidence is fully reconstructible from history by hand.
