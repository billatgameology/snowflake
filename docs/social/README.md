## The rules that bind anything outward-facing

1. **Claims.** Charter §1.5 governs outward-facing prose exactly as it governs UI labels.
   The corpus is scrupulous about the difference between a measurement, a fit, an eye guide,
   and a convenient formula ([ch. 13](../education/chapters/13-the-frontier.html)). A hook
   may not quietly upgrade one to another.
2. **Rule 13.** Interpretation is gated like evidence — a skeptical pass *before* it ships.
   A voiceover is interpretation, and it travels further than anything else here.
3. **Rights.** The education figures are © Kenneth G. Libbrecht and are not redistributed.
   Any social asset that shows a source figure is blocked. Our own renders are ours;
   Bentley (Wikimedia PD) and USDA LT-SEM are usable with attribution.
4. **No agent posts.** External contact is maker-gated
   ([stretch-sharing](../stretch-sharing-and-investigation.md)). Agents draft; the maker
   sends.
