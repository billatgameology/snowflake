# Plan — Five-entry Journey sample week

- **Phase:** Maker-directed exploration, outside Phase 6 scope
- **Status:** done
- **Started:** 2026-08-09
- **Last touched:** 2026-08-09 by OpenAI Codex

## Goal

Create one complete fictional week that makes the Snow Crystal Journey numbering, media, channel,
correction, and reconstruction specifications concrete. The example should let the maker see the
ordinary editorial flow and the archive identities together without implying that any artifact,
account, publication, scientific result, or remote response actually exists.

## Done when

`docs/journey/SAMPLE-WEEK-01.md` contains:

- five connected entries, `SCJ-0042` through `SCJ-0046`, on five different days;
- one coherent question-to-discovery-to-correction-to-recap arc;
- every retained channel in `SOCIAL-MEDIA.md` used at least once across the week, while no entry is
  forced onto every channel;
- the audience-facing label, canonical URL, Previous/Next, topic, correction, and synthesis links;
- complete illustrative artifact, release-manifest, destination-publication, and global-event IDs;
- house media choices, sample destination copy, accessibility, provenance, and localization notes;
- a known automatic cross-post, an ambiguous attempt reconciled without retry and with no second
  object found in the named check, a technical release repair, a material partial correction, and a
  recap with an explicit ordered source list;
- a channel-coverage audit, daily maker workload, and reconstruction walkthrough; and
- conspicuous fictional-data boundaries, including reserved URLs and non-digest placeholders.

## Approach

Use a mature Journey week beginning Monday 2026-08-10 in `America/Los_Angeles`, with entry numbers
that are examples rather than allocations. Use `snowcrystal.example` for every owned or remote URL
and mark all filenames, byte counts, digests, account IDs, response IDs, and platform observations
as illustrative. Never borrow a real Phase 6 run, metric, evidence label, or remote platform claim.

Build one source packet per entry, then distribute only the useful derivatives. Spread discovery,
conversation, evergreen, community, direct, and live destinations across the five days. Keep the
visible public story simple (`Journey 0042`); show the archive suffixes and event chains in the
worked records below it. Label every simulated crystal view as model output whose morphology is not
validated against measurement.

## Tried and rejected

- **Publish every entry to every destination.** Rejected: it hides the system's selective-channel
  purpose and creates an implausible solo-maker burden.
- **Use the Journey's first five numbers.** Rejected: a mature sample week better explains why
  community, live, and direct-message channels already exist, while avoiding any suggestion that
  this is the actual launch plan.
- **Use plausible hashes and platform URLs.** Rejected: realistic-looking invented evidence can be
  mistaken for a real archive. The sample uses visibly non-operative placeholders.
- **Borrow a real solver checkpoint for realism.** Rejected: the task is to exercise the content
  schema, not reinterpret unfinished Phase 6 evidence or create an outward scientific claim.
