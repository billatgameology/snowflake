## Context and decision

The completed longer facet comparisons retain basal-only hollowing at both warm anchors.
The narrower prism/completion interaction produced no deepening-cavity lead. The next question
is whether hollowing survives when the existing basal dip depends on local geometry instead
of being applied everywhere. The active discovery plan records primary-source limits and a
retained-geometry calculation: short exposed-face chords occur at tips and recessed regions,
so their selection must not be called rim-only physical SDAK.

Add `experimentalBasalWidthCells` to the constant-environment CPU experiment, requiring M1
base metadata and aggregate-v6. Select the existing M1 basal pair only when the minimum
integer exposed-support chord meets the threshold; otherwise use no-dip. Keep prism no-dip,
geometric completion enabled and rough/inhibited rules unchanged. The plan and attachment
spec define the geometry, including a minimum over both support faces for `[02]`. This is a
P4 mesoscopic rule, not the source's molecular width law or a complete M2 implementation.
The same local coefficient feeds Robin relaxation and fill. Cache only on attached geometry,
with a refresh before the next relaxation after attachments.

The separate identity is `post-phase10-local-basal-width-v1`. No combination with other
experimental flags, timeline changes or ordinary checkpoint export is supported. The plan
registers four rows, two thresholds at each warm anchor, and reuses the already completed
no-dip/basal-only controls. Existing experiments and producer records remain unchanged.
