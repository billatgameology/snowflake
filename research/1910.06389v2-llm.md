# Snow Crystals monograph — local LLM research bundle

This index documents the reproducible local extraction of Kenneth G. Libbrecht's *Snow Crystals*
monograph, arXiv:1910.06389v2. The canonical local source is `1910.06389v2.pdf`; the official
source record is <https://arxiv.org/abs/1910.06389>.

## Provenance

- Source file: `research/1910.06389v2.pdf`
- Source SHA-256: `f6cd58ab841f841bcc310d2f722459122f7850cda9681ae0c7d1877bf21ef471`
- Source size: 25,611,913 bytes
- PDF pages: 523
- Extractor dependency used for this build: PyMuPDF 1.26.5 / MuPDF 1.26.10
- Generated folder: `research/1910.06389v2-llm/`

The generated folder is a 327 MB local cache and is intentionally gitignored under decision 0004.
It contains full extracted text and rendered copyrighted images, so do not force-add it. This
tracked index and the scripts are the reproducible record.

## What the bundle contains

- Searchable Markdown for all **523 of 523** PDF pages, with explicit PDF and printed-page metadata.
- **376** numbered figure cards, each with a caption, structured evidence JSON, visual crop,
  figure-plus-caption crop, and a link to the complete rendered page.
- **279** complete rendered pages: one for every page containing at least one detected caption.
- `figure-index.md`, `figures.jsonl`, and `pages.jsonl` for text search and programmatic lookup.
- Candidate temperature, pressure, duration, percentage, and qualitative-condition mentions. These
  preserve raw wording and are labeled `machine-extracted`, never automatically verified.
- A deterministic 12-card extraction-QA sample spanning photographs, diagrams, plots, and
  multi-panel figures. The reviewed sample had zero missing caption/image associations. Two crops
  retained harmless neighboring text, recorded in `qa-review.json`.

## Rebuild and verify

From the repository root:

```sh
python3 scripts/build_pdf_llm_bundle.py \
  --force \
  research/1910.06389v2.pdf \
  research/1910.06389v2-llm

python3 scripts/verify_pdf_llm_bundle.py \
  research/1910.06389v2-llm \
  --source-pdf research/1910.06389v2.pdf
```

That verifies the generated structure. Next inspect every entry in `qa-sample.json`, record the
results in local `qa-review.json`, and add `--require-qa` to the verification command for the final
strict check. A rebuild deliberately removes the previous review because changed crops must be
inspected again.

The strict verification result for this build was:

```text
PASS: 523 pages, 376 figures, 279 rendered pages, 12 QA samples
```

The generator replaces an existing output folder only when `--force` is present and the folder
contains its generator marker. It refuses to delete an unrelated directory.

## LLM query workflow

Search first; do not load the whole monograph into context:

```sh
rg -n -i 'temperature|supersaturation|pressure|capped column' \
  research/1910.06389v2-llm/figure-index.md \
  research/1910.06389v2-llm/figures \
  research/1910.06389v2-llm/pages
```

For a matching figure:

1. Open `figures/fig-X.Y/evidence.md`.
2. Inspect `visual.png` for morphology and labels.
3. Inspect `evidence.png` for the image/caption association.
4. Open the linked complete page when layout or surrounding prose matters.
5. Cite the PDF page and verify important formulas, units, and physical claims against the
   canonical PDF.

The image can support a morphology observation. Conditions normally come from the caption, labels,
or prose. Their association is evidence only when the source explicitly connects them; an image
alone does not prove its growth temperature or supersaturation.

## Known limitations

- PDF text preserves the source characters but some mathematical glyphs and subscripts degrade
  during extraction. Verify equations against the rendered page and canonical PDF.
- Figure crops are conservative layout associations. Every card links to a complete page so an LLM
  can recover context when a crop contains extra material or an unusual layout.
- Nearby text blocks are selected by geometric proximity only and are labeled accordingly. They are
  retrieval aids, not automatically linked evidence.
- The structured condition detector finds candidate phrases; it does not decide whether a value is
  an experimental input, a measured output, an axis value, or a comparison from another study.
